# XIV MIDI Studio 0.3 target requirements

1. Native MIDI regions (split, drag, trim, Ctrl-drag duplicate, loop, join) with Undo/Redo, boundary-safe partial notes, and MIDI export.
2. Quantize selected regions independently: straight, tuplets, swing, strength, start/end; separate explicit project-wide quantize button. No automatic project quantize.
3. Piano roll selected-note operations: octave up/down, Extend to Next Note, Force Legato, Remove Overlaps; allow percussion.
4. Playback: next/previous measure seek without stopping, click-to-seek without stopping, independent timeline scrolling and Follow Playhead control.
5. Draggable amber playback-only cycle range with repeated playback, click toggle, no impact on MIDI export.
6. Keyboard pitch selection: click for whole current track; click-drag vertical inclusive range; Ctrl additive.
7. Track SoundFont preset dropdown with auto-rename; included default SoundFont if distribution permitted.
8. Traditional black/white keys regardless of dark theme.
9. Rebrand executable and installer; refreshed README / attribution.
10. First-run and Help-menu feature tutorial after UI stabilizes.
